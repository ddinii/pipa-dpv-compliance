# P2-R09 — 사고 시점 일치 검증 (신규 Rule, v1.1)

- **입력:** 사고 기록의 F2-05 (`incidentDate`), 통지문의 F2-08 (`notice_incident_time`).
- **GREEN:** 같은 시점이면 GREEN (ISO 8601 표기가 달라도 동일한 UTC 시각은 일치).
- **YELLOW:** 두 시점이 다르거나 값·시간대가 불명확한 경우. 확인이 필요하다.
- **N/A:** 통지문 부재가 명시적으로 확인된 경우.
- **RED 미사용:** 입력된 두 문서 간 일관성을 점검하며 위반 여부나 통지 기한을 판단하지 않는다.
- **연결:** 각 사고의 `hasNotificationNotice`로 연결된 통지문만 비교한다.
- 기존 P2-R03, F2-05/F2-08 Fact, 온톨로지 v1.0을 변경하지 않는다.
- 기존 18개 Rule을 보존하고 1개의 v1.1 Rule을 추가한다.
